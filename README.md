# WiFi ADB

一个轻量的原生 macOS Android 无线调试连接工具，使用 SwiftUI 构建。保存常用手机后可一键查找地址、核验身份并重新连接。

## 功能

- 配对码配对、局域网发现和手动地址连接。
- 保存设备、重命名和一键重连，支持无线调试端口变化。
- 同时显示多台设备，区分 USB、无线和模拟器连接。
- 手动刷新，无后台定时扫描；连接、断开后更新状态。
- 页面内显示错误，只有移除已保存设备时需要确认。
- 数据仅存本机，无操作历史列表、账号服务或遥测。

## 使用

1. 打开 **WiFi ADB.app**。应用会优先查找 Android Studio SDK 内的 `platform-tools/adb`，也可以在设置中自行选择。
2. 手机与 Mac 接入可互通的局域网，在手机的开发者选项中打开 **无线调试**。
3. **已经与这台 Mac 配对**：在「发现设备」中连接，或者在「添加设备」输入无线调试主页显示的 IP 和连接端口。成功核验后会记住设备。
4. **首次配对**：在手机点「使用配对码配对」，在应用的首次配对表单填写配对端口、六位配对码，以及无线调试主页上的连接端口。两个端口用途不同。配对码不写入命令参数、记录或磁盘。
5. 之后在「我的设备」点击 **一键重连**。可以给设备起名，例如「vivo 测试机」「小米测试机」。

「已发现」表示检测到无线调试服务，不代表已经连接。「已连接」需要 ADB 在线且身份匹配。**连接、重连、断开直接执行，不弹成功提示；只有移除记录需要确认。** 移除记录只影响本应用，不会撤销手机上的调试授权。断开只针对所选无线连接，但使用同一个 ADB 服务的 Android Studio 等工具也会失去该连接。

应用启动时读取一次状态，之后通过工具栏「刷新」或 **⌘R** 手动更新。连接、保存、断开及更换 adb 路径后会更新相关结果；切换页面、回到前台或重新打开窗口不会触发扫描。没有定时轮询，空闲时不反复调用 ADB。界面保留上次读取的状态与更新时间，设备在其他工具中发生变化后需手动刷新。

首页先展示所有当前连接，再展示常用设备。USB 和无线可以属于同一台手机，因此当前列表按连接条数显示；无线在线数按已核实身份合并，尚未核实的连接单独计数。设备名中的空格及 ` (2)` 等服务重名后缀会完整保留。断开使用 ADB 当前登记的完整连接标识，不会用发现到的 IP 替换它。

## 一键重连的条件

- 手机开机、连接 Wi-Fi，并且无线调试保持开启。
- Mac 与手机之间能够通信。公司访客网、客户端隔离或阻断 mDNS 的网络可能无法自动发现。
- 设备仍信任这台 Mac。撤销授权或更换电脑后需要重新配对。
- 连接端口变化时，应用优先通过当前发现结果定位设备；无法确定身份时提示手动处理，不会凭手机型号猜测设备。

软件不能远程开启已经关闭的无线调试，也不能保证绕过手机系统的省电策略。需要长时间亮屏调试时，可给手机供电，并开启开发者选项的「充电时不锁屏」。应用不会替你修改这些手机设置。

## 本地数据

默认保存于 `~/Library/Application Support/WiFiADB/`，记录设备名称、硬件标识、最近成功连接地址与时间，用于重连。操作过程不保存为历史日志。应用不包含云端服务，不上传设备数据，不保存配对码，不执行 `adb kill-server`、全局断开、重置授权或手机清数据。

## 系统和构建

- 运行环境：macOS 14 或更新版本。已在 Apple Silicon 验证；Intel Mac 尚未验证。
- 需要本机已有 [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)；应用不捆绑或自动下载 ADB。
- 构建需要 Xcode 16 或更新版本（Swift 6+），以及 `python3`。无第三方 Swift 包依赖。
- 手机需支持无线调试配对；手机系统设置和网络策略可能影响可用性。

```bash
git clone https://github.com/haleihuixingzhuangdiqiu/wifi-adb-mac.git
cd wifi-adb-mac
swift test
bash Scripts/build-app.sh
open dist
```

默认输出 `dist/WiFi ADB.app`，将它拖入「应用程序」即可安装。脚本按当前 Mac 架构构建，生成代码绘制的图标和应用包，并做本地 ad-hoc 签名；未进行 Apple 公证或 App Store 发布。

## 开发验证

`Scripts/mock-adb.py` 是独立的验收替身，不连接真实手机。可以用以下环境变量启动编译后的应用进行测试：

```bash
WIFIADB_ADB_PATH="$PWD/Scripts/mock-adb.py" \
WIFIADB_DATA_DIR="$PWD/.build/acceptance-data" \
WIFIADB_MOCK_DIR="$PWD/.build/mock-state" \
  "dist/WiFi ADB.app/Contents/MacOS/WiFiADB"
```

测试替身内的六位码固定为 `123456`，只用于虚构测试设备，不能用于任何真实手机配对。它的状态文件可控制发现、在线、端口变化及失败场景。正式使用不要设置这些测试环境变量。

源码包含协议解析、地址校验、重连身份约束、配对码处理和进程执行等测试。桌面界面验收使用隔离的模拟 ADB；真实 vivo / 小米无线网络与系统省电行为需要在实际手机上进一步核验。

## 代码结构

- `Sources/ADBCore`：ADB 命令、输出解析、身份校验、连接协调与本地存储。
- `Sources/WiFiADB`：SwiftUI 界面与应用状态。
- `Tests/ADBCoreTests`：不依赖手机的行为和边界测试。
- `Scripts`：应用构建、图标生成与隔离测试替身。
